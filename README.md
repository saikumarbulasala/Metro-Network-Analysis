# Optimal Route Finder - Python

Python port of the Java Dijkstra-based Hyderabad Metro shortest route finder.

## Run

```bash
python3 metro.py
```

Then follow the prompts:
- `1` — list all station names
- `2` — shortest distance between two stations (meters) + full route
- `3` — shortest time between two stations (minutes) + full route

Station names are case-sensitive and use underscores, e.g. `LB_Nagar`, `Lakdi-Ka-Pul`.
